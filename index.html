Начало работы

Сохраните этот файл как index.html и откройте двойным щелчком в современном браузере. На вкладке «Исходные данные» заполните проект, даты, период и объёмы категорий. Изменение поля применяется при выходе из поля или нажатии Enter. Расчёты работают без интернета. Для Excel требуется загрузка библиотеки из интернета; для графиков предусмотрена встроенная резервная отрисовка.

Модель и пересчёт

Исходные данные проекта и девяти категорий общие для всех сценариев. У каждого из трёх сценариев собственные сезонность продаж, сезонность цены, инфляция и ручные значения количества. Начальные предпосылки сценариев одинаковы: измените их сами. Дата ввода — справочная, на цену и распределение не влияет. Модель не подбирает цены и не оптимизирует продажи.

Один расчёт формирует календарь → распределяет свободный объём с учётом ручных значений → определяет остатки, цены, площадь и выручку → накопительные итоги → KPI → таблицы и графики → сохранение. Экспорт использует те же расчётные данные.

Количество и ручные значения

Свободный объём = исходное количество − сумма ручных продаж.
Автоматические продажи месяца = свободный объём × вес месяца / сумму весов автоматических месяцев.

Для целых значений применяется метод наибольших остатков: сначала берутся целые части, затем оставшиеся единицы добавляются месяцам с самыми большими дробными частями. При равенстве приоритет у более раннего месяца. Если все доступные веса равны нулю, распределение равномерное.

Измените количество в первом блоке «План продаж и цены». Жёлтая ячейка и знак ✎ обозначают ручное значение, в том числе ноль. Кнопка ↶ возвращает автоматический расчёт. Кнопка сброса удаляет все ручные значения только текущего сценария после подтверждения. Если все месяцы зафиксированы, нераспределённый объём остаётся непроданным.

Корректировки привязаны к календарному месяцу (ГГГГ-ММ). При изменении даты или срока значения вне периода сохраняются, но не участвуют в расчёте; при возврате периода они восстанавливаются. Уменьшение объёма ниже суммы сохранённых ручных значений любого сценария отклоняется.

Цена, площадь и выручка

Цена₁ = стартовая цена.
Ценаₜ = ценаₜ₋₁ × (1 + сезонное изменение цены / 100) × K инфляции.
K инфляции = 1 в месяцах 1–6; с месяца 7 — (1 + инфляция / 100).
Средняя площадь = общая площадь / количество (при нуле — 0).
Площадь месяца = продажи × средняя площадь.
Выручка = площадь месяца × цена; паркинг: продажи × цена места.

Цены и выручка округляются до копеек на завершённых этапах расчёта; итоговая выручка складывается в целых копейках. Площадь рассчитывается без промежуточного округления и показывается с двумя знаками: сумма отображаемых округлённых площадей может отличаться на несколько сотых от итога. Переключатель 0/2 знака меняет только отображение цены. Средняя цена реализации — выручка без паркинга / реализованная площадь без паркинга. Накопительная выручка — сумма выручки с начала периода.

Нулевая сумма сезонных процентов не означает строго нулевое сложное изменение за год: коэффициенты цены перемножаются. Изменённые пользователем сезонные наборы не нормируются автоматически. Среднее весов и сумма сезонных процентов отображаются для контроля.

Сценарии, сохранение и Excel

Переключайте сценарий в исходных данных. «Копировать настройки из базового сценария» заменяет только три вида предпосылок текущего сценария, сохраняя его ручные продажи.

Автосохранение и кнопка «Сохранить проект» используют LocalStorage этого браузера и этого файла. Для переноса на другой компьютер или резервной копии используйте «Скачать данные проекта» и «Загрузить данные проекта». Сохранение HTML-файла само по себе не встраивает в него введённые данные.

Ключ LocalStorage: developer-sales-planner. Версия структуры: 2. Объект содержит version, state (проект, категории, выбранный сценарий, настройки трёх сценариев, точность цены), calculatedPlans (результаты трёх сценариев) и savedAt. При восстановлении данные проверяются, результаты пересчитываются. Предусмотрена миграция версии 1; неизвестная новая версия не перезаписывается автоматически.

«Экспорт в Excel» выгружает выбранный сценарий в семь оформленных листов: исходные данные, коэффициенты, план продаж, ценообразование, итоги по месяцам, итоги по категориям, свод проекта. В ячейках — числовые результаты текущего расчёта, а не Excel-формулы. Цены разных единиц измерения не суммируются: итог строки цен — средневзвешенная цена реализации. При отсутствии продаж она равна нулю. Используемая Excel-библиотека не сохраняет закрепление областей; заголовки повторяются для каждого блока.

Для проверки работы с библиотеками использованы их загруженные оригинальные файлы; отдельно проверен режим недоступности CDN.
